# Análisis de Amazon
## Frontend

Es la parte que ve y utiliza el usuario. En Amazon incluye:
- Página principal.
- Buscador.
- Productos y sus imágenes.
- Carrito.
- Botones y menús.
Se desarrolla principalmente con HTML, CSS y JavaScript.

## Backend
Es la parte que funciona en los servidores. Se encarga de:
- Gestionar usuarios.
- Buscar productos.
- Gestionar el carrito y los pedidos.
- Procesar pagos.
- Gestionar la base de datos.

## Modelo cliente-servidor

El usuario utiliza Amazon desde su navegador (cliente). Cuando realiza una acción, el navegador envía una petición al servidor.

El servidor procesa la petición, consulta la información necesaria y devuelve una respuesta al navegador.
Usuario -> Navegador (Frontend) -> Servidor (Backend) -> Base de datos -> Servidor -> Navegador
